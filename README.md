# InkFlow

A Procreate-style drawing app for Android (Kotlin, no third-party dependencies) that imports Procreate
`.brush` and `.brushset` files.

## Build

Open this folder in Android Studio (Koala or newer) and press Run, or from a terminal:

```
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
```

Requires JDK 17 and the Android SDK (platform 34). Min Android version: 7.0 (API 24).
The included GitHub Actions workflow (`.github/workflows/build.yml`) also builds the APK on every push.

## Features

- Pressure, tilt and stylus-eraser support; palm rejection; hover brush outline
- Brush engine: spacing, flow, opacity, scatter, size/opacity/rotation jitter, follow-stroke rotation,
  tilt stretch, stabilisation, grain textures, mip-mapped tips
- Paint, Smudge and Erase tools, each with its own brush; 12 built-in brushes
- Layers: up to 60 (memory permitting), opacity, 17 blend modes (10 need Android 10+), alpha lock, lock,
  duplicate, merge down, reorder
- Undo/redo that stores only the pixels each stroke touched
- Pinch/pan/rotate; two-finger tap = undo, three-finger tap = redo; long-press = eyedropper
- HSV colour picker, hex entry, recent colours
- Projects (`.inkflow`, layered), PNG/JPEG export to Pictures/InkFlow with share, image import as layer
- Autosave and restore

## Procreate brush import

Import from the menu (multiple files allowed) or open a `.brush` / `.brushset` from a file manager.

Both are ZIP archives. For each brush InkFlow reads `Brush.archive` (an NSKeyedArchiver binary plist,
parsed by `brushfile/BinaryPlist.kt` and `KeyedArchive.kt`), `Shape.png` (tip) and `Grain.png` (texture).
`Reset`, `QuickLook`, `Signature` and `Sub*` folders are skipped, and `brushset.plist` sets the order.

Mapped settings: `name`, `plotSpacing` (stored squared), `paintSize`, `dynamicsPressureSize`,
`dynamicsPressureOpacity`, `shapeScatter`, `shapeRotation`, `shapeRandomise`, `dynamicsJitterSize`,
`dynamicsJitterOpacity`, `grainDepth`, `shapeInverted`, `textureInverted`.

Limits to know about:

- Procreate's format is unpublished. The key names above come from community reverse-engineering and
  were **tested only against archives generated by `tools/make_sample_brushes.py`**, not against files
  exported by Procreate itself. Expect some real brushes to look different, and report/adjust the mapping
  in `ProcreateMapper.kt`.
- Not reproduced: wet mix/paint blending, speed and falloff dynamics, dual-brush second tip, built-in
  Procreate shapes/grains that are referenced but not bundled in the file, per-brush blend mode.
  Each import lists what was skipped.
- `.procreate` canvas files are not supported (brushes only).

## Tests

The importer is pure Kotlin and is tested on the JVM:

```
python3 tools/make_sample_brushes.py samples
kotlinc app/src/main/java/com/inkflow/paint/brushfile/*.kt tools/jvmtest/ImporterTest.kt -d out
java -cp out:kotlin-stdlib.jar ImporterTestKt samples
```
